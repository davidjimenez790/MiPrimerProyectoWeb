# MiPrimerProyectoWeb

Primer proyecto web del módulo de Ingeniería Web (Guía 1 – Configuración del entorno de desarrollo web).

Página en HTML5, CSS y JavaScript sobre las herramientas del desarrollo web: Visual Studio Code, Google Chrome (DevTools), Live Server y Git/GitHub.

## Estructura

```
MiPrimerProyectoWeb/
├── index.html
├── css/styles.css
├── js/main.js
└── img/logo.svg
```

## Cómo ejecutarlo

1. Clona o descarga el repositorio.
2. Abre la carpeta en Visual Studio Code.
3. Clic derecho en `index.html` > **Open with Live Server**.
